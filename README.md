## Proyectos Destacados

### Aplicación de anuncios con calendario

- **Qué resuelve:** Permite publicar y consultar anuncios de eventos en un solo lugar y ver qué eventos hay en cada día mediante un calendario.
- **Tecnologías:** Java y Android Studio.
- **Funcionalidades:**
  - Agregar anuncios con la información necesaria y una imagen.
  - Mostrar todos los anuncios en una lista.
  - Filtrar los eventos de un día con el calendario.
- **Repositorio:** [POO4_2P_BOZZA_REYES](https://github.com/DanielaBv127/POO4_2P_BOZZA_REYES)

### Sistema de gestión de alquiler de vehículos

- **Qué resuelve:** Diseño de una base de datos relacional para administrar los procesos de una empresa de alquiler de vehículos, con Budget Rent a Car Ecuador en Guayaquil como caso de estudio.
- **Tecnologías:** SQL y MySQL Workbench.
- **Funcionalidades:**
  - Gestión de clientes, reservas y contratos de alquiler.
  - Control de la flota vehicular y de sus mantenimientos.
  - Pagos, facturación, seguros, sanciones y reportes, con roles de usuario y permisos definidos.
- **Repositorio:** [ProyectoSBD](https://github.com/stephJJK/ProyectoSBD)

### Festivanimal: Sitio web de un evento comunitario

- **Qué resuelve:** Sitio informativo sobre un evento de bienestar animal en Guayaquil, con actividades, servicios veterinarios, aliados y testimonios de asistentes recogidos en entrevistas.
- **Tecnologías:** HTML, CSS, plantilla Helios de HTML5 UP y GitHub Pages.
- **Funcionalidades:**
  - Páginas de inicio, actividades, servicios y experiencias, con menú de navegación.
  - Carrusel de marcas aliadas y mapa de ubicación.
  - Testimonios basados en siete entrevistas realizadas durante el evento.
- **Repositorio:** [Proyecto-Festivanimal](https://github.com/DanielaBv127/Proyecto-Festivanimal)
- **Demo:** [Ver sitio publicado](https://danielabv127.github.io/Proyecto-Festivanimal/)
